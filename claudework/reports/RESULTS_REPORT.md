# C 题结果报告

微网与外部电网电力调控策略。全部数字由 `code/run_all.py` 生成，运行约 30 秒。

## 一、统一口径

| 项目 | 取值 | 说明 |
| --- | --- | --- |
| 调度粒度 | 10 分钟，每天 144 段 | 功率 × 1/6 h 得区间电量 |
| 储能容量 | 1200 ~ 10800 kWh | 初始 6000 kWh（2025-01-01 0:00） |
| 充放电功率 | 每段 ≤ 5000/6 kWh | |
| 充放电效率 | 充电 ×0.9，放电 1:1 | 往返 0.9，损耗全记在充电侧 |
| 售电 | 不允许 | 光伏富余只能充入储能或弃光 |
| 购电量约束 | 结算按计划购电量计费 | 缺额由 5 倍价紧急购电补齐 |

**附件3 的时间对齐**：附件3 的“预报 h 小时”指发布时刻起第 h 个小时，即区间
`(T+h-1, T+h]`。所以 6:00 发布的“预报 1 小时”对应当天第 36~41 个十分钟区间。
使用时在该小时的 6 个十分钟段内取常值。

**附件5 模板的表头错位**：模板“计划购电量”第一行标签是 `0:10-0:20`，比当天
实际区间整体错开一格。模板结构不改，按行号映射：第 2 行放第 0 个区间
（0:00-0:10），第 145 行放第 143 个区间（23:50-24:00）。

## 二、模型

四问共用一条 10 分钟粒度的线性规划，决策量是分段购电量 `x_t`、充电量 `c_t`、
放电量 `d_t`、储电量 `s_t` 和弃光量 `w_t`：

```
min  Σ p_t x_t
s.t. x_t + PV_t + d_t - c_t - w_t = L_t         功率平衡
     s_t = s_{t-1} + 0.9 c_t - d_t              储能递推
     1200 ≤ s_t ≤ 10800,  0 ≤ c_t, d_t ≤ 5000/6
     x_t ≥ 0,  w_t ≥ 0                          不允许售电
```

问题1 额外要求 `s_143 = s_{-1} = 6000`；问题2~4 逐日滚动，每天计划要求
24:00 回到 0:00 的电量，与问题1 的日循环口径一致。

### 日前预测

题面没有给问题2 的负载和光伏预测，统一取**此前 7 天的平均值**（问题3、4 的
光伏改用附件3 的预报，负载仍用 7 日均值）。

### 安全裕度（报童模型）

紧急购电价是正常价的 5 倍，所以计划不能只按预测值买。设区间 t 的预测误差
`e_t = (实际负载-预测负载) - (实际光伏-预测光伏)`，多买 1 kWh 的边际成本是
`p_t`（买多了只能弃掉），少买 1 kWh 的边际成本是 `5 p_t · P(e_t > y_t)`，两者
相等给出

```
P(e_t > y_t) = 1/5   →   y_t = e_t 的 0.8 分位点
```

取此前 28 天同一区间的误差样本估这个分位点，把它直接加到计划购电量上。
裕度只影响购电量和弃光量，不改变储能充放电决策，所以可以事后叠加。

效果（问题2，全年）：

| 安全裕度 | 计划购电费 | 紧急购电费 | 合计 |
| --- | ---: | ---: | ---: |
| 不加（纯按预测买） | 11,113,157 | 12,846,738 | 23,959,895 |
| 0.5 分位 | 13,819,915 | 4,460,221 | 18,280,136 |
| 0.7 分位 | 15,049,241 | 2,114,019 | 17,163,260 |
| **0.8 分位（采用）** | **15,702,558** | **1,323,842** | **17,026,400** |
| 0.9 分位 | 16,569,871 | 688,402 | 17,258,273 |

最优分位点正好落在理论值 0.8，全年比不加裕度省 **693 万元（29%）**。

### 一个关键恒等式

在“储能严格按计划充放电”下，把计划的功率平衡式代入执行缺额，得到

```
执行缺额 = e_t - w_t
```

也就是说**紧急购电量只由预测误差决定，与储能怎么调度无关**。这解释了为什么
问题2 的费用结构是“计划买得少、紧急补得贵”，也正是问题3 要压缩的对象：
预报越准，紧急购电越小。

### 问题3 的滚动结算

0:00 的预报定初始计划；6:00、12:00、18:00 只重排该时刻之后尚未执行的区间。
调整相对 0:00 计划结算，两条规则合起来是

```
调整后购电费 = Σ p·x_adj + 0.5 Σ p·|x_adj - x_plan|
```

（增购部分按 1.5 倍、减购部分按 0.5 倍，合并后恰好是这个对称形式。）
总费用 = 该项 + 紧急购电费。

### 问题4 的价格

价格同样只能在 0:00 之前观测到，用此前 7 天同一时段的平均电价做预测，
按附件4 的实际电价结算。

## 八、可改进方向

1. **储能自适应执行**：现在严格按计划充放电，执行缺额全靠紧急购电。若允许
   储能在实际缺电时放电，紧急购电还能进一步下降，代价是充放电量偏离计划。
2. **跨日储能**：现在每天 24:00 回到 0:00 电量。由于电价日型固定，跨日套利
   空间很小，但连续阴天时放开跨日约束可以省一点。
3. **价格预测**：问题4 用的是 7 日均值价，换成带日内形状的预测模型可以再降。
